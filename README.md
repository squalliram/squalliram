> **About this repository**
>
> This repo is also a small **React app** (originally bootstrapped on CodeSandbox). The source under `src/` renders a single-page portfolio layout for *IFK Consultants Ltd* — a header with section links (Home / Work / About / Contact), a hero with a sample image, a customers grid, an about section and a contact form.
>
> Available scripts (from `package.json`):
>
> | Script          | Purpose                            |
> | --------------- | ---------------------------------- |
> | `npm start`     | Run the app in development mode.   |
> | `npm run build` | Build for production.              |
> | `npm test`      | Run the test runner (jsdom env).   |
> | `npm run eject` | Eject from Create React App.       |
>
